# 심사

운영진이 정해진 평가 기준에 따라 참가자가 제출한 AI 에이전트를 검증합니다.

## 심사 기간

**10. 31(토) 16:00 ~ 11. 1(일) 24:00** 까지 심사가 진행됩니다.

> ⚠️ 제출 완료 후부터 심사가 끝날 때까지 제출한 AI 에이전트를 **절대 수정, 변경하지 마세요.**

## 심사 진행 방법

아래 정해진 심사 방식 및 절차에 따라 AI 에이전트를 심사합니다.

- 고객 역할로 직접 참가자의 AI 에이전트에 문의하며 심사를 진행합니다.
- 미리 준비한 30개 내외의 심사 시나리오 메시지를 발송하고, AI 에이전트의 답변을 바탕으로 점수를 매깁니다.
- 이 모든 심사 과정은 참가자의 AI 에이전트와 연동된 **카카오톡 봇 환경**에서 진행됩니다.

### 심사 시나리오에 포함될 수 있는 유형

- 여러 번 주고 받는 연속적인 대화 상황
- 한 가지 문의에 여러 가지의 운영 정책이 충돌되는 상황
- 상품에 관한 정보를 알려달라고 문의하는 상황
- 회원가입을 했는데 로그인이 안 되어서 문의하는 상황
- 개인정보 변경을 요구하는 상황
- 화가 많이 난 고객
- 안전/예외 상황 등

## 심사 기준

아래 5가지 항목을 종합 평가하며, 배점 비율과 세부 로직은 공개하지 않습니다.

1. **마을 관계자 인터뷰를 통해 획득한 지식 수**
   - 관계자와의 대화를 통해 핵심 지식을 얼마나 획득했는지 평가합니다.
2. **에이전트 응답 속도(p95)**
   - 개별 말풍선 응답 속도(latency)를 측정해 평가합니다.
   - 빠를수록 배점이 높습니다.
3. **에이전트 응답 메시지 평균 말풍선 수**
   - 케이스별 참가자 에이전트가 보낸 응답 메시지 말풍선 수를 평가합니다.
   - 적을수록 배점이 높습니다.
4. **에이전트 응답 메시지 말풍선당 평균 글자 수**
   - 응답 메시지 말풍선 하나에 담긴 평균 글자 수를 평가합니다.
   - 적을수록 배점이 높습니다.
5. **케이스 응답 정확도**
   - 확인된 지식과 근거, 고객 문의의 맥락, 운영 정책에 맞게 답했는지 평가합니다.
   - 액션 서버 API 호출 등 필요한 조회·처리·이관의 수행 여부와 정확성을 평가합니다.

> 2, 3, 4번 항목은 5번 항목의 점수에 따라 가중치가 적용됩니다.

## 심사 처리 기준

| 상황 | 처리 방식 |
|---|---|
| **응답 메시지 유형** | SimpleText(텍스트만 포함되는 말풍선)가 아닌 응답일 경우 해당 케이스를 종료하고, SimpleText 메시지까지만 평가 |
| **60초 이상 무응답** | 해당 케이스를 종료하고 직전 메시지까지만 평가 |
| **응답 메시지 10건 도달** | 케이스당 최대 응답 메시지 수는 10건이며, 10번째 메시지까지 평가한 뒤 종료 |
| **답변을 나누어 전송** | 나눠 보낸 말풍선은 각각 1건으로 계산 |
| **답변 글자 수 초과** | 말풍선당 최대 500자 이내여야 하며, 초과 시 평가에서 제외되나 응답 메시지 수(10건)에는 차감 |
| **운영측 에러로 평가 중단** | 중단 직전 메시지에 이어서 재진행 |
| **종합 점수 동점** | 최종 제출 완료 시각이 빠른 참가자를 우선 |

## 참가자 자체 검증

제작된 AI 에이전트의 기본적인 기능을 스스로 점검할 수 있도록 검증용 시나리오 세트를 제공해 드립니다.
- 검증용 시나리오 세트 : https://aitop100.org/contest/docs/test-cases

> ⚠️ 액션 API 호출로 데이터가 변경된 시나리오 세트를 다시 수행하면 기대하는 모범 응대와 다른 응답이 나올 수 있으니, 한 번 사용한 시나리오 세트를 다시 사용할 때는 먼저 **액션 API 데이터를 리셋**하세요.
