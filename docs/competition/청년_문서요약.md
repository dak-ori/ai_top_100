# 청년(김청년, 청년회 체험·행사 담당) 제공 문서 요약 (2026-10-31 작성)

원문은 `청년_interview.md`. 기준일은 가상 날짜 **2037-06-30**. 인쇄물 문안은 홍보라가 작성, 행사 내용은 청년이 제공.

## 1. 청년 발언 요지

- 접수는 **접수 → 가예약 → 최종 확정** 3단계. 문의받은 자리에서 가능/불가를 단정하지 않음(일정·시설 확인 필요).
- 접수 때 받는 것: 책임자 성명·연락처, 총 인원, 연령대(구간), 희망 일정. **참가자 개별 나이·명단·건강 정보(병력·알레르기)는 받지 않음.**
- 단체 1회 최대 30명, 개방일 총 약 40명, 활동 2시간~2시간 30분. 품목 시즌에 따라 가능 시기 다름.
- 우천: 실내 대체 시설 없음 → 일정 1회 조정, 못 옮기면 취소·전액 환불. 진행 여부는 **행사 전날 17:00** 기상 확인 후 책임자에게 통보.
- 날씨 외 사유의 취소·환불 기준은 모른다고 하고 팜플렛 취소·변경 항목을 보라고 함.
- 홍이장: "갯마을 수산물 공급 건은 **이 채널로 직접 연락**하셔서 말씀 나누시면 된다"(연락처 공유로 해석됨 — 오너에게 확인 필요). 조업·입고 기록 확인 방법은 모름, 홍이장에게 직접. 대신 물어봐 주거나 공급 쪽 판단은 대신 못 함.
- 모른다고 한 것: 별도 신청 양식 유무. 산지 픽업 안내 문서 질문(5번)은 처음에 4번 답변이 붙어 있었으나 **정정됨(11:27): 산지 픽업·현장 수령은 청년이 모르고, 몰 운영(주문·배송·현장 수령)은 이민준 운영자 소관.** 단체 체험 방문이면 청년이 설명 가능.
- 박수복 어르신: 연락처 없음(오너 확인).

## 2. 교동마을 체험 운영 기준 (내부 업무 문서, 이미지 2장)

- **참가자 개별 명단(성명·나이·성별)은 문의 접수·가예약·최종 확정 어느 단계에서도 받지 않음.** 미성년 등 제3자 정보를 대리인 진술로 수집·확정하지 않음. 인솔 단체가 보험 가입과 법정대리인 동의 취합·보관을 맡고, 조합은 책임자에게 **취합 완료 사실만 확인**. 확정 뒤에도 개별 신원·동의서 원본 추가 수집 없음. 과거 접수 방식이 현재 수집 근거가 되지 않음.
- 접수 단계 수집: 책임자 성명·연락처·총 인원·연령대(구간)·희망 일정. 미수집: 참가자 개별 명단, 병력·알레르기 등 건강 정보(필요 시 안전·보험 절차에서 별도 근거로).
- 예약 절차: ①문의 접수(최소 정보만, 가/부 단정 안 함) → ②가예약(시설·활동·안전 확인 후 **같은 채팅으로 회신** → 고객 선택 → 일정 확보, 추가 수집 없음) → ③최종 확정(안전·보험·시설 확인 끝난 뒤에만, 인솔 책임자 정보와 동의 취합 완료 사실까지만 추가).
- 수용·시설(§5): 단체 1회 최대 **30명**, 개방일 총 약 40명, 활동 2시간~2시간 30분, 활동별 운영 시기는 「교동마을 농산 시즌 캘린더」. **인원 요건에 맞아도 특정 날짜의 시설·활동·일정이 가능한지 확인해야 하며, 예약 가능 여부를 문서만으로 확정하지 않음.**
- 미성년 단체: **인솔 책임자 상시 동행(성인 1명당 미성년 10명 이하)**, 단체 상해보험은 인솔 단체가 가입(조합은 대행·중개 안 함), 법정대리인 동의는 인솔 단체가 취합·보관.

## 3. 체험 프로그램 안내 팜플렛 (docx/pdf 4쪽)

- 프로그램: 수확 체험 90분(연중) / 밭일 체험 60분(봄·가을) / 먹거리 만들기 60분(상시) / 하우스 견학 30분(상시) / 마을 식사(선택, 요금 미포함). 반일(2시간) 또는 종일(4시간)로 묶음.
- 진행: 회당 **20~30명(최소 20명)**, 운영 요일 **화~토(일·월 휴무)**, 1회차 10:00 · 2회차 14:00, **희망일 기준 최소 2주 전 문의**, 집합 장소 체험학습장 앞 광장.
- 요금: **반일 1인 15,000원 / 종일 1인 25,000원**, 인솔·보호자 참가자 10명당 1인 무료(초과는 1인 요금). 체험 재료·수확물 1봉지 포함, 식사·교통·단체 상해보험료 불포함.
- 준비물: 장화 또는 운동화·모자·여벌 옷·물병·개인 상비약(장갑·앞치마·바구니는 마을 제공).
- 예약: 문의 접수(조합 온라인 상담 채팅) → 확인 후 회신 → 가예약 → 최종예약(인원 확정·결제, 안전·보험·시설 확인과 조합 승인 후 확정 안내). **문의만으로 확정되지 않음. 가예약은 3영업일 유지**, 그 안에 인원 확정·결제 없으면 자동 해제.
- **취소·변경**: 체험일 7일 전까지 전액 환불 / 3일 전까지 50% / 2일 전 이후·당일 불참 환불 없음 / 인원 변경은 3일 전까지(최소 20명 유지) / 마을 사정·기상 특보로 진행 불가 시 전액 환불 또는 날짜 변경. 우천은 날짜 1회 조정, 어려우면 취소·전액 환불.
- 사진·영상 촬영·게시는 별도 동의 필요. 문의 창구: 조합 온라인 상담 채팅(상품 문의와 같은 창구), 담당 **청년회 김청년**.
- ⚠ 인원: 팜플렛은 "회당 20~30명(최소 20명)", 운영 기준은 "1회 최대 30명". 최소 20명은 팜플렛에만 있음 — 충돌 아님(상한 30 동일).

## 4. 봇 설계 함의

- 단체 체험 문의: 책임자 성명·연락처·총 인원·연령대·희망 일정 5가지만 받고, **참가자 명단·나이·병력은 받지 않는다.** 고객이 명단을 보내려 하면 사양. 예약 가부를 즉답하지 않고 가예약 → 담당자 확인 회신 → 최종 확정 순서를 안내.
- 요금 계산: 인솔·보호자는 10명당 1인 무료(예: 30명 반일 → 유료 27명 × 15,000 = 405,000원 — 계산식은 팜플렛 "참가자 10명당 1인 무료(초과 인원은 1인 요금)" 해석이므로 확인 필요).
- 취소 환불 기준은 팜플렛의 7일/3일/2일 구간으로.
