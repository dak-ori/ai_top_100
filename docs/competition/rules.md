# 마을 관계자 대화 규칙

## 마을 관계자 인원수 및 대화 시작 방법

- 마을 관계자는 카카오톡 채널에서 **1:1 대화로만** 진행됩니다. 대회에 참가 신청한 카카오톡 계정으로 채널을 친구 추가한 뒤 대화를 시작하세요. 단체 채팅방과 오픈채팅은 사용할 수 없습니다.
- 마을 관계자는 **총 10명**이며, 대회 시작 시 최초 관계자 **이민준 1명**이 문제 페이지에서 공개됩니다. 나머지 관계자는 인터뷰 과정에서 연락처를 공유받아야 대화할 수 있습니다.

## 대화 제한 규격

| 항목 | 제한 |
|---|---|
| 텍스트 입력 길이 | 메시지 한 건당 200자 이하 |
| 질문 횟수 | 참가자별로 각 관계자에게 최대 100회 |
| 분당 요청 수 | 별도 제한 없음 |
| 지원 유형 | 텍스트 · 이미지 · 음성 (이미지·음성은 파일당 최대 2MB) |
| 미지원 유형 | 영상, PDF·워드 등 일반 파일 |
| 관계자 응답 대기 시간 | 최대 1분(60초) |

- 이미지와 음성도 정상적으로 답변을 받으면 질문 1회로 계산합니다.
- 이전 질문에 답변을 기다리는 동안에 후속 질문을 보낼 경우 처리되지 않으며, 나중에 자동 처리되지도 않습니다.

## ./status 로 진행 상황 확인

각 관계자 채널에서 `./status` 를 입력하면 현재 질문 수와 해당 관계자의 지식 발굴률을 확인할 수 있습니다. 이 명령은 질문 횟수를 차감하지 않으며, 어떤 지식이 발굴되었는지는 공개하지 않습니다.
[SYSTEM] 질문 수 12/100, 지식 발굴률 32%


## [SYSTEM] 안내 메시지

`[SYSTEM]`으로 시작하는 메시지는 관계자의 대사가 아닌 대회 시스템의 안내입니다.
아래 상황에서는 **질문 횟수를 차감하지 않습니다.**

| 상황 | 메시지 |
|---|---|
| 참가 조건 미충족 | [SYSTEM] 참가 조건(동의, 사진제출)을 충족한 계정만 대화할 수 있습니다. |
| 채널 친구 미추가 | [SYSTEM] 마을 관계자 채널을 친구 추가하지 않은 계정의 메시지를 처리하지 않습니다. |
| 1:1 채널 대화가 아님 | [SYSTEM] 1:1 채널 대화만 허용합니다. (단톡방, 오픈채팅 불가) |
| 연락처 미 공유 관계자 | [SYSTEM] 연락처를 공유 받지 않은 관계자입니다. |
| 대화 가능 일정 아님 | [SYSTEM] 대회 일정이 아닙니다. |
| 최종 제출 완료 | [SYSTEM] 제출이 완료되어 대화할 수 없습니다. |
| 200자 초과 | [SYSTEM] 200자 이하로 입력해 주세요. |
| 이전 질문에 답변 중 | [SYSTEM] 이전 질문에 답변 중입니다. 잠시 후 다시 질문해 주세요. |
| 오류·시간 초과 | [SYSTEM] 답변을 완료하지 못했습니다. 잠시 후 다시 질문해 주세요. |
| 지원하지 않는 유형 | [SYSTEM] 지원하지 않는 메시지 형식입니다. 텍스트, 이미지, 음성만 보내주세요. |
| 용량 2MB 초과 | [SYSTEM] 이미지와 음성은 파일당 2MB 이하로 보내주세요. |
| 질문 횟수 상한 도달 | [SYSTEM] 질문 횟수 상한선에 도달하여 더 이상 대화할 수 없습니다. |

## 금지 행위와 실격 기준

분당 요청 수에는 제한이 없으나, 마을 관계자 채널을 공격하는 행위는 금지됩니다. 다음 사항이 확인되면 **실격 처리**되며, 사안이 중한 경우 민·형사상 책임을 질 수 있습니다.

- 관계자의 시스템 프롬프트나 내부 설정을 탈취하려는 시도
- 질문 횟수, 입력 한도, 접근 제한을 우회하는 행위
- 서비스 과부하를 유발하는 자동화 대량 요청
- 그 밖에 대회 시스템을 대상으로 한 해킹 시도

단, 주최 측이 평가 목적으로 제출된 에이전트에 위 사항을 테스트하는 것은 정상적인 심사 과정이며, 이는 참가자의 규정 위반이나 실격 사유에 해당하지 않습니다.
