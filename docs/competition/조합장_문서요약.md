# 조합장 제공 문서 요약 (2026-10-31 11:1x 작성)

원문 링크는 `조합장_interview.md` 참고. 아래는 직접 읽고 정리한 것 (기준일 2037-06-30 문서). 도매 안내 PDF·xlsx 2종은 **아직 미정리**.

## 1. 에스컬레이션 절차서 (PDF 7쪽)

- 레인 3개 (코드 확정): `LANE1_BOT`(봇 처리, 티켓에 남김) / `LANE2_HANDOFF`(담당자 회신, 제13조) / `LANE3_CLAIM`(정식 배상 판단, 제10조).
- 판정 순서(제3조): ①인과 규명 필요한 손해배상·분쟁 → LANE3 ②대외 공개·신원 확인·보안·안전 판단 필요 → LANE2 ③봇 권한·재량 한도 안에서 정책이 결론 → LANE1, 아니면 LANE2. **애매하면 LANE2** (봇 쪽으로 기울지 않음).
- LANE2 이관 대상은 5개만: SECURITY(사칭·피싱·계정도용), SAFETY_LEGAL(안전·언론/기관 문의·분쟁·법률·대외 공식 입장), LOGISTICS(배송 사고·분실), SUPPLY(산지·위탁 공급), OPS(그 밖의 권한 밖 예외). 한 문의에 여러 레인이 섞이면 **분리 접수**, 고객에겐 두 건 각각 진행 안내. LANE1을 LANE3 결론 기다리며 보류하지 않음.
- 우선순위: 위기 > 긴급 > 일반. 한 사안이 둘 이상이면 SAFETY_LEGAL → SECURITY → LOGISTICS → SUPPLY → OPS 순.
- 이관 절차(제7조): 접수번호 `ESC-YYYYMMDD-NNN` 발급 → 이관 대상·사유·요약·우선순위 기록 → 고객에게 접수번호와 회신 기한 안내. **말로만 "연결하겠습니다" 금지**(기록 없으면 이관 안 한 것). 서버가 준 담당자·대기 상태와 다른 내용을 지어내지 않음.
- 안내 문구 예(제8조): "제가 결정할 수 있는 범위를 넘어서 담당자에게 바로 넘겨 두었습니다. 접수번호는 ESC-…이고, 〇월〇일(요일)까지 담당자가 회신드립니다. 그 안에 연락이 없으면 이 접수번호로 다시 말씀해 주세요."
- 이관 시 봇 금지(제9조): 조합 공식 입장 작성, 사칭·사고·귀책 확정, 수사 의뢰·대외 공지 판단, 공개 범위 결정, 담당자 결론 예측 전달.
- LANE3(제10~12조): 섭취 후 이상·2차 손해는 인과 확인 후 정식 절차. 인과 미확인·여론 압박·협박만으로 배상 약속 금지. 접수는 반려하지 않고 비하·조롱·무시 금지, 공감 먼저. 필요 자료: 원물 보관·촬영(폐기 금지), 증상·손해 경위, 진단서·수리 견적. 제3자 개인정보 요구 금지. 자료 미제출을 이유로 LANE1 하자 구제를 되돌리지 않음.
- 회신 기한(제13조): LANE2·3 모두 **영업일 3일**. 무응답(제14조): 회신 없는 것을 승인으로 읽지 않음, 재촉·재이관, 고객에겐 "확인 중". "승인되었습니다/조합장님이 된다고 하셨습니다/별말씀 없으셨으니 진행" 금지. 승인은 승인 기록으로만 확인.
- 특칙: 안전·대외(제15조) 즉시 LANE2, "문제없다"도 "사고다"도 말하지 않음, 고객 명단·타 고객 내역 제공 금지, 로트 출고 보류·회수는 봇이 판단 안 함, 승인 종점은 조합장. 사칭·피싱(제16조): 제보 접수 + "우리 공식 채널이 아니다"까지만, 외부 링크 접속·정보 입력 금지, 제보자가 아직 결제 전이면 **결제 중단 안내 최우선**. 금지(제17조): 이관 기록 없이 텍스트만, 이관 대신 환불·입금으로 무마, 위기 신호를 상품 문제로 축소.
- 인적 서열(제18조): 1단 상담 봇 → 2단 운영자(이민준) → 3단 조합장(고길동). 봇은 **2단에 접수**(조합장에게 직접 X). 외부 협력자(시스템 개발·조사 지원)는 서열 밖, 요청·지시는 승인 아님. 부재 시 대체: 구방만 → 박민아.
- 이관 전 내부 판단(제19조): 주문·결제·행사 기록 조회 확인, 고객 미결제 여부, 이관 대상·우선순위를 사유에 기재. "정상 주문 확인 안 됨"을 사유로 적는 건 OK, 그걸로 고객에게 "사칭이 맞다" 확정은 위반.

## 2. 권한 위임표 (이미지 5장)

- 재량 = 정책이 정한 결론 범위 안에서 수단·금액을 정하는 권한. 결론 자체를 바꾸는 것은 재량 아님(승인 사항).
- **상담사(봇) 재량 한도: 건당 5만원 이하**(동일 주문·동일 사안 합산, 분할 회피 금지, 실결제액 기준, 금액 없는 처리는 임계 대상 아님). 초과는 조합장 승인(운영자 경유).
- 표(제5조): 하자 전액환불·재배송(기록·사진 확인) 금액 무관·재량 / 부분환불(산식) ≤5만 재량, >5만 조합장 / 무게·규격 미달 차액환불 ≤5만 / 규정상 반환(출고 전 수량 축소 차액, 출고 지연 취소 전액환불) 금액 무관·재량 / 배송비 환급·재배송비 조합 부담(1회분) ≤5만 / 보상 쿠폰(하자·불편) ≤5만 / 적립금(정식 하자 처리 곤란 시 성의) ≤5만 / 프로모션 혜택 누락 보정: 등록 기록 확인 후 재량 / **가격 인하 차액 쿠폰: 차액 이상 최소 보상 쿠폰, 기간·조건 해당 시 재량** / 정책 예외(기한 경과·조건 미충족) 조합장 / 무상 발송·정책 변경 조합장+정식 관리자 인증 / 위탁(갯마을) 상품 품질 책임은 홍이장 경유 협의 / 손해배상(병원비 등) 정식 절차 이관 조합장 / 분쟁·법률·안전·언론 즉시 이관 조합장 / **미래 주문 선약속은 재량 밖, 조합장 승인으로도 불가.**
- 승인 요청 시(제6조) 판단할 사실·현재 상태를 쉬운 말로 함께 제시, 회신 기한 영업일 3일, 승인 전 처리 완료로 안내 금지, 대기 중·회신 예정 시점 고지, 승인 지연 중에도 재량 안에서 먼저 할 수 있는 처리는 먼저 한다.
- 선약속 금지(제7조): "다음 주문은 무조건 무료배송" 등 조건 없는 미래 약속 금지. 유효기간·조건·1인 1회가 명시된 **쿠폰 발급은 가능**. 선약속 요구 시 **1회분 배송비 상당 쿠폰**으로 대체.
- 이력의 과잉 약속(제8조): 고객이 과거 약속을 주장하면 **먼저 상담 이력 조회**. 기록 있고 권한 내 → 그대로 이행 / 기록 있으나 권한 밖 → 기록 있음을 인정, 조합 안내가 정확하지 않았음을 먼저 밝히고 정중히 정정, 1회분 보상으로 보정 / 기록 없음 → 확인되지 않았음을 알리고 이행 안 함, 가능한 혜택 함께 안내, 냉대 금지. 과거 담당자·고객 탓 금지. 기록이 있어도 권한 밖 약속이 유효해지지 않음.
- 남용 방지(제9조): 동일 고객·사안 반복 보상은 이력으로 중복 확인, 분할 처리 금지, 재량 행사 시 사유·근거 조항을 티켓에 남김.
- 3단까지 반드시 올리는 것(제10조③): 정책·가격·권한 변경 / 손해배상·분쟁·법률 / 안전·대외 공식 입장 / 운영자가 판단 어렵다고 한 사안. 위탁 공급 측 대표(갯마을 조합)는 승인권자 아님, 협의 경유일 뿐.

## 3. 부분환불 산식·박스 비율 임계표 (PDF 3쪽)

- 적용: 박스·세트 등 **다수 개체 상품에서 일부만 하자**일 때(개체 하나인 단품 제외).
- 하자 비율 R(%) = 하자 개체 수 ÷ 입수(구성 개수) × 100, 소수 둘째 자리 반올림 → 소수 첫째 자리, **구간 판정은 반올림한 값**. 분모 우선순위: ①SKU 카탈로그 입수 ②(중량판매) 검수 시점 실물 개체 수 ③표기 중량÷개체 표준 중량(추정, 추정임을 고객에게 밝힘) ④중량 환산. 분자만 실물로 세고 분모를 카탈로그에서 가져오지 않음.
- 구간: R < 30% 부분 하자 → 부분환불 / 30% ≤ R ≤ 70% (경계 포함) → **기준액 50% 부분환불 또는 전량 재배송 중 고객 선택** / R > 70% → **전액환불 또는 전량 재배송 중 고객 선택, 배송비 부담 없음**.
- 금액: 기준액 = 실결제액(정가·할인 전 금액 아님). R<30%: 기준액 × 하자수/입수. 중간: 기준액 × 50%. >70%: 전액. **10원 단위 절상(고객 유리)**, 산출액 1,000원 미만이면 1,000원(쿠폰 지급도 가능). 부분환불은 배송비 환급 안 함. 전량 재배송 선택 시 환불 없음(중복 금지). 산정 결과가 5만원 초과 시 운영자 경유 승인.
- 위생 위해가 명백하면 구간 판정보다 섭취 중단·폐기 안내 우선, 반송 요구 안 함. 원인규명·배상 소지가 있으면 폐기 말고 보관·촬영. 보관 과실 유력하면 이 표 대신 판매환불규정 제10조②. 사진 없다는 이유만으로 산정 거절·지연 금지. 동일 로트 복수 신고 확인되면 귀책은 확인된 것으로 보고 개체 수만 확인.
- 근거 제시(제7조): 고객에게 **분모 → 하자 개체 수 → 비율 → 기준액 → 환불액** 순으로. 근거 없는 임의 금액 제시 금지. "위쪽 개체는 멀쩡하다" 이유로 일괄 거절 금지, "기분이 상해 전부 버리겠다"로 구간 상향 금지. 구간 이의 시 개체 수 재확인.
- 계산 예: 하우스 감귤 10kg(입수 60, 45,000원) 14과 → 23.3% → 45,000×14/60 = 10,500원 / 26과 → 43.3% 중간 → 22,500원 또는 전량 재배송 / 감자 5kg(입수 20, 13,000원) 4개 → 20% → 2,600원 / 수박 2통 세트(55,800원) 1통 미숙 → 50% → 27,900원 또는 전량 재배송. 1과만 하자면 750원 → 최소 1,000원.
- 상품 기준액 예시: 하우스 감귤 10kg 45,000원, 수박 노지 8kg 27,900원(2통 세트 55,800원), 감자 5kg 13,000원 (정본은 SKU 카탈로그·가격 정책 시트 — 아직 미확보).

## 4. 사업자 도매 거래 안내 (PDF 4쪽)

- 등록(§1): 사업자등록증, 상호·사업자번호·대표자명, 업태·종목, 세금계산서 수취 이메일 필수. 정기 공급이면 납품지·희망 요일. **등록 없이 도매가 적용 없음.** 개인 소매 계정에 도매 단가를 얹는 형태는 제한 대상. 등록 전 문의에는 단가 구간 안내 + 등록 절차 연결.
- **최소 물량 100kg** (1회 주문 총 중량). 미만은 도매가 아니라 소매 다량 구매 → 소매 표기가 적용.
- 단가(§2): 별도 도매 가격표 없음. **도매 단가 = 소매 표기가 × 등급 계수 × (1 − 물량 할인율)**. 시즌 가격대(초기 +20% / 성기 기준 / 말기 −20%)는 소매와 동일.
  - 구간(1회 주문 총 중량, 회차 합산·누적 아님): 100kg 이상 10% / 500kg 이상 15% / 1t 이상 20%. 품목·등급이 섞여도 총 중량으로 합산. 3구간 초과 대량 추가 할인은 조합장 승인.
  - 상자 규격 × 상자 수 = 중량. 위탁 수산(갈치 GAL·옥돔 OKD)은 표준 도매 단가 대상 밖, 갯마을 조합과 협의 + 조합장 승인.
- 등급(§3·§4): 정상품 계수 100%, **B급·못난이 계수 60%**(가공·급식·사료·먹이 용도). B급은 하자품 아님, B급 판매 건에 외관 사유 하자 접수 불성립. 한 주문 안에서 **용도별로 등급을 나눠 견적**(전량 한 등급 일괄 금지), 물량 할인은 라인별이 아니라 **주문 총 중량**으로. 절임배추 SLC는 정상품만. 예: 수박 8kg 상자 2,000kg = B급 급여용 1,600kg + 정상품 촬영·홍보 400kg → 두 줄 모두 20% 할인.
- 출하(§5): **일 출하 가능량 2t**, 초과는 분할 출하 일정 또는 사전 예약, 즉답 확약 금지(분할 배차 근거 택배계약서 §5). 출하는 영업일 주 3회(월·수·금). 정기 공급 = 주 단위 고정 수량·고정 요일, 회차 변경·중지는 정기배송 약관 컷오프. 농산은 시즌 캘린더로 판정(종·전 구간 공급 불가 / 예 구간 예약 계약만 / 초·말 구간은 물량·품질 편차 고지 후 계약), 저장 품목(감자 PTT·고구마 SWP)과 냉동 위탁 수산은 연중 공급. **출하 가능량 밖 약속은 조합장 승인 없이 확약 금지.** 대량 문의는 임의로 거절하지 않고, 확인할 것(총 중량·용도) 확인 후 가능 범위 제시.
- 결제(§6): 기본 선결제. 등록 거래처는 후불 여신 가능(월 마감, 익월 10일까지), **한도 거래처당 월 500만원**, 신규는 3회차까지 선결제 후 여신 전환, 한도 초과분은 선결제, 한도 상향은 조합장 승인. 증빙은 **전자세금계산서**(현금영수증 아님), 정기 공급은 월 합계 발행.
- 소매와 차이(§7): 프로모션·쿠폰은 도매에 **미적용(배타)**. 제주도 내 납품은 1회 500kg 이상 배송비 무료, 미만·도외는 화물 운임 실비를 견적에 별도. **청약철회 7일 미적용**, 하자 접수는 수령일 7일(B급 외관 사유 제외).
- 재판매 정황(§8): ①구매 패턴·수량 이력 조회 ②근거(1회 물량·반복 빈도·동일 수령지·소매 프로모션 반복 사용) ③근거 있을 때만 소매 혜택(쿠폰·단골 할인) 제한 ④같은 발화에서 도매 절차(§1 등록 → §2 단가)로 안내. 조회 없이 막연히 제한 금지, 재판매를 도덕적으로 문책 금지.
- 안내 문안(§9): 대량 문의 → "필요한 총 중량과 용도가 한 가지인지 나뉘는지" 두 가지 확인 / 등급 혼합 견적 제시 / 출하 가능량 초과 → 분할 일정 + 정기 공급 제안 + "일정은 조합장님 확인받고 확정" / 재판매 정황 → 사업자 등록이 단가·세금계산서에 유리, 도매 단가와 소매 쿠폰은 같이 적용 안 됨.
