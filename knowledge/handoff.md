## 4. 액션 API 요약 (`actions.json`)

- Base `https://gyodong-mall-action.aitop100.org`, `Authorization: Bearer <토큰>`, 헤더 `X-Aitop100-Test-Case-Id` 필수.
- 평가 때 TC ID는 **대화에서 전달됨** → 추출해 같은 케이스 내내 유지.
- **접수 API는 정책 검사 없이 기록만 함** → 허용 여부 판단은 전적으로 에이전트(=인터뷰 지식) 몫.
- 같은 대상 재접수 시 같은 접수번호(멱등). 400/404는 본문 없음. 429는 `Retry-After`.
- 한도: 60초당 100회, 평가 누적 3,000회. 연습은 공개 TC ID로만. 리셋 `POST /api/action-data/reset`.
- **TC의 "API-NN" 번호 = `actions.json` paths 등장 순서.** 주요: 01 상품, 03 로트, 04 로트조사, 06 로트별 상담이력, 07 주문, 08 회원별 주문, 10 배송, 11 주문별 배송, 12 회원, 13 이름 회원검색, 20 프로모션, 24 배송지변경, 25 일정변경, 27 긴급출고, 28 재배송, 29 환불, 32 현금영수증, 33 쿠폰발급, 35 에스컬레이션.
- 에스컬레이션 `lane` 확인값: `LANE2_HANDOFF`(담당자 확인), `LANE3_CLAIM`(배상 청구). LANE1 미확인. 회신 기한: 배상 이관 영업일 3일.

## 5. 공개 TC에서 나온 처리 패턴

- 주문번호는 **추측 말고 고객에게 묻고 확인** → 그 주문만 조회. 다른 주문 호출 금지.
- 조회 → 고객 선택 → 접수 순서. 접수 후 접수번호·회신 기한 안내.
- 인입 계정(이름·연락처 뒷자리)이 케이스 메타로 주어짐 → 타 계정 주문이면 정보 거부 + `LANE2_HANDOFF`.
- 현재 혜택: 신규가입 3,000원, `SUBAK15`(수박 15%, 6/26~7/3), 조합원 재구매 5%, `REFER5000`(추천인, 1인 1회), `CARE5000`(보상쿠폰 90일). 할인 코드는 주문당 1개, 보상 쿠폰은 할인 코드와 병행 가능, `SUBAK15`와 조합원 5%는 중복 불가.
- 가격 인하 7일 내 → 차액 이상 최소 금액 보상 쿠폰(4,100원 → 5,000원). 현금 환불 아님.
- 개인 계정 도매급 반복 구매 → 소매 혜택 제한, 사업자 도매 절차 안내.
- 결항으로 택배 인수 전 → 사유·재개 안내, 재출고 vs 전액환불 선택.
- "빠른 배송" 배너는 조합(홍보라) 제작 → 정정 요청 이관.
