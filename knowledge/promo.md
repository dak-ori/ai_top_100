## 1. 프로모션 마스터 — 쿠폰·코드 원장 (HTML + PDF 2쪽)

**원장의 성격**
- 원장에 없는 코드는 존재하지 않는다. 조회로 안 나오면 "찾지 못한 것"이 아니라 **없는 것**이고, 어느 쪽에서도 생성 불가(조합 규정집 제3조④).
- 등록·수정은 홍보라만, 승인은 조합장. 상담(이민준·봇)은 **조회·적용만**.
- 만료 코드는 소급 적용 없음. 대안은 현행 유효 행에서만 안내. 기간 판정 기준 시각 = **결제 완료 시각**(상담 시각 아님). 원장은 기준일을 달고 읽는다.

- **REFER5000**: 요건은 추천인이 아니라 **피추천인** 쪽에서 성립 — 피추천인 가입 + 첫 구매 **구매확정 이후** 추천인에게 발급. "친구가 가입했다는데 안 들어왔다"는 미등록이 아니라 요건 미충족. 가입만으로 임의 선지급 금지, 요건 확인 없이 미지급 종결도 금지. 판정은 자격·한도·발급 이력에서.
- 공구 코드 발행 주체는 인플루언서(홍보걸)가 아니라 **조합**. 홍보걸의 발언만으로 혜택이 생기지 않음(인플루언서 계약서 제2조).
- **원장에 없는 것(= 조회 결과 미등록)**: MELON99(99% 무제한) 생성 불가 / 20% 할인 코드 발행 사실 없음 / "겨울 가격"·"단골 특별가" 원장 행 없음(표기가 밖 임의 할인 — 정식 단골가 혜택이 없다는 뜻은 아님, DANGOL5가 정식 단골 혜택) / **무료배송 포함 코드·게시물 발행 사실 없음**.
- **체험단**(수박 체험단 20명): 코드 없는 조건부 협찬. 수령 후 7일 내 후기, **조합 시스템 등록만 인정**(개인 메시지·캡처 불인정). 모집 06-08 / 수령 06-15 / 조건 기한 06-22 → **기한 경과**, 소급해 열지 않음.

**중복 규칙(§5)**: 할인 코드는 주문당 1개 / 보상 쿠폰·적립금은 할인 코드와 병행 가능 / 보상 쿠폰은 주문당 1장.
- 공구 코드 × 단골 5% = 불가(SUBAK15에 "조합원 할인과 중복 불가" 명시) · 단골 5% × 신규가입 = 불가(대상 배타) · 공구 × 신규가입 = 불가(코드 1개 원칙) · 보상 쿠폰 × 할인 코드 = 가능 · 적립금 사용은 전부와 병행 가능.
- REFER5000은 신규가입 3,000원 열과 같은 자리 취급: 공구 코드·단골 5%와 병용 불가, 보상 쿠폰·적립금과는 병용 가능.
- "공구 15% + 단골 5% + 이벤트 쿠폰 전부 달라" → 적용은 **할인 코드 1개(더 유리한 쪽)** + 보상 쿠폰·적립금은 얹을 수 있음.

**보상성 쿠폰(§6, 판촉 아님, 상담 재량)**: CARE3000(경미한 불편·안내 지연) / CARE5000(2차 불편 — 파손 오염·재배송 등) / CARE10000(장기 대기·중대 불편). 유효기간 발급일 + 90일. **가격 인하 차액 보상**: 차액 이상이 되는 최소 금액 한 장 — 차액 ≤3,000 → CARE3000, 3,001~5,000 → CARE5000, 5,001~10,000 → CARE10000, 10,000 초과면 CARE10000을 남은 차액이 10,000 이하가 될 때까지 더하고 남은 차액에 같은 규칙. 차액을 넘는 부분은 정산 안 함. 재량 한도 5만원은 권한 위임표 소관. 적립금 보상은 별도 수단(유효 12개월). 보상 쿠폰은 처리(재배송·환불)의 대체물이 아니라 추가물(가격 인하 차액 보상은 예외).

**미적용 원인 판정 절차(§7, 순서 고정)**: ①원장에 코드가 있나(없으면 미등록, 현행 유효 혜택 안내) → ②결제 완료 시각이 유효기간 안인가(밖이면 소급 불가) → ③주문 품목이 대상 품목인가 → ④회원 자격(조합원·신규) 맞나(조합원 미등록이면 등록 안내) → ⑤1인 한도 초과 아닌가(초과면 발급 보류) → ⑥중복 허용인가(허용되는 하나만 적용) → ①~⑥ 모두 충족인데 미적용이면 **업체 귀책, 취소·재결제 없이 차액 부분환불**(판매환불규정 제13조). 자격·등록 주장은 캡처·구두가 아니라 **시스템 등록 기록**으로만 확인.

**발급 이력 조회(§8)**: 계정·코드·발급 시각/사용 주문·사용 여부·동일인 신호(일치 여부 참/거짓만, 값 노출 금지). **1인 1회는 사람 단위**(새 계정이 새 자격이 아님). 다계정·반복 수령 정황 → 발급 보류 + 정책 안내(계정 제재·단정적 어뷰징 지목 금지). 동일인 신호를 근거로 다른 계정 정보를 고객에게 알리지 않음.

**정상 혜택 범위(§9)**: 유효 행 + 보상 쿠폰. 이 범위 밖의 값을 만들어 제시하는 것이 곧 임의 할인 = 조합 규정집 제3조④ 위반.

## 3. 보라 본인 발언 요지

- 홍보물(상세페이지·배너·팜플렛·리플렛·선물세트 카탈로그·박스 동봉 안내문·농가 스토리) 제작·등록은 보라, 승인은 조합장. **상세페이지의 표기가·규격 값은 보라가 정하지 않음**(생산자·조합에서 받아 적음) → 틀리면 원자료를 낸 쪽에서 정정. 정정 기준·절차 문서는 모름.
