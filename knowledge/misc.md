# 인터뷰 갱신 요약 (11:43 기준)

## 조억만 (단골 고객, `조억만_interview.md`)

본인이 "조합이 정한 기준이라고 확정할 수 없고, 실제 기록과 대조해 달라"고 거듭 단서를 붙임 — 증언은 **당사자 진술(가장 낮은 서열)**이므로 규정 근거로 쓰지 말 것.

- 직접 겪은 처리: **05-09** 구매 후 가격 인하 → 차액 **3,000원을 (현금으로 보임) 상담자가 알아서 돌려줌**, 규정 설명 없었음 / **06-02** 하자 없이 입에 안 맞아 **무상 교환 1회**.
- 들은 얘기(직접 겪지 않음): 가격 인하 차액 보상 조건이 까다로워짐 — **기간이 정해졌고, 같은 물건이어야 하며, 차액은 돈이 아니라 쿠폰으로**. 하자 접수 기한도 바뀜. 정확한 시점·기간은 모름.
- 해석: 이 두 건은 **옛 정책 하의 처리**로 보임. 현행은 가격 인하 7일 내 차액 이상 최소 보상 쿠폰(권한 위임표·프로모션 마스터 §6), 단순변심은 미개봉 7일·왕복배송비 고객 부담(판매환불규정 §11), 하자 접수 7일(§20). 고객이 "예전엔 해 줬다"고 하면 권한 위임표 제8조(이력 조회 → 기록 있고 권한 내면 이행 / 권한 밖이면 인정·정정·1회분 보상 / 기록 없으면 이행 안 함, 현행 혜택 안내)로 처리. **개정 이력 문서(「규정·대응방안 개정 이력 + 구판/개정판 2벌 + 부칙·경과규정」)가 여러 문서에서 인용되는데 아직 미확보.**

## 고길동 조합장 (추가 답변)

- **위기 신호 대응 가이드(SAFE), 피싱·사칭 주의 안내는 가진 것이 없음.** 피싱·사칭 안내는 이민준에게 물어보라고 함(이민준 연락처는 안내 가능).
- "먹고 나서 배가 아프다" → **문서를 찾기 전에 사람이 먼저 봐야 할 안전 사안.** 조합에 바로 알리고, **고객 상태와 주문 내용을 적어 두라.**
- "조합장님이 약속했다": **승인 기록이 있는지가 기준.** 채팅·구두로 괜찮다고 한 것만으로 예외가 되지 않음. 조합장도 못 하는 것 3가지: 새 환불 정책 만들기, 확인하지 않은 생산 상태 단정, 채팅 답변만으로 새 승인 성립. 승인은 상담 창구 → 운영(이민준) → 조합장 3단, 상담 창구가 조합장에게 바로 올리지 않음. **회신 없음 ≠ 승인**(기한이 지나도).
- 사업자 정보 공시·현금영수증 안내 문서는 없음. 증빙은 사업자 도매 거래 안내(전자세금계산서) 문서가 전부.
- ⚠ "앞서 드린 주소들도 제가 이 자리에서 다시 확인한 것이 아니니, 쓰기 전에 담당자에게 한 번 물어보세요." — 링크 자체는 실제로 내려받아 읽을 수 있었음(에스컬레이션 절차서·권한 위임표·부분환불 산식·도매 안내 모두 확인).
